# Security Policy

## Supported Versions
Security updates are actively applied to the latest release branch (`v3.x`).

| Version | Supported          |
| ------- | ------------------ |
| 3.2.x   | :white_check_mark: |
| 3.1.x   | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability or timing channel leak in the BitNet-130 RTL or firmware, please do not disclose it publicly on GitHub Issues.

Instead, please send an email to `cherukurigowtham851@gmail.com` with:
- Description of the issue
- Steps to reproduce
- Affected modules or scripts

We will review reports within 48 hours and work with you on a coordinated disclosure.
